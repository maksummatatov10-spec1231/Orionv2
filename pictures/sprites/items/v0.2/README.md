# v0.2: иконки предметов

Обновлены обе источники иконок, чтобы предмет в руке, в инвентаре, в курсоре строительства и на земле выглядел одинаково:

- `*_icon_atlas_*.png` — regions `item_259`, `item_269`, `item_273`, `item_325` в атласе `items`, 16×16.
- `*_icon_ui_*.png` — отдельные UI-битмапы `Images.ITEM_*`, 32×32, оригинальная альфа-маска сохранена.

Предметы: камень, земля, земля с травой, булыжник.
